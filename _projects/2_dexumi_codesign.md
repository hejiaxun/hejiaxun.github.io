## Public page in preparation

This project page will organize the work into four public-facing modules:

1. Dexterous-hand data collection and simulation teleoperation.
2. MANO-driven physical control for wearable interfaces.
3. Ergonomic and biomechanical engineering diagnostics.
4. Parametric CAD reconstruction and Co-design infrastructure.

The final page will clearly distinguish open-source DexUMI reproduction from personal extensions. Company-confidential figures, implementation details, and unapproved internal metrics will not be published.
